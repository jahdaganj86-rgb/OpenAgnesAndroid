# Open Agnes Android

Debug-APK wird ausschliesslich via GitHub Actions gebaut und als Release-Artifact bereitgestellt.

## Installation (Moto G84, Android 13/14)

1. Debug-APK aus dem neuesten GitHub Release herunterladen.
2. Unter Einstellungen → Apps → Sondererfassung → "Unbekannte Apps installieren" für den Installer (Browser/File Manager) erlauben.
3. APK installieren und öffnen.
4. API-Key über das Hamburger-Menü eintragen und speichern (lokal verschlüsselt auf dem Gerät).
5. Bild auswählen, Prompt eingeben, Bearbeitung starten.

Hinweis: Keine API-Keys oder Secrets werden im Repository gespeichert.
